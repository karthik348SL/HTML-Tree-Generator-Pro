# Privacy Policy

**HTML Tree Generator Pro** respects your privacy.

## Data Collection

This extension does **not** collect, store, transmit, or sell any personal information.

## Local Processing

All HTML DOM inspection and processing is performed locally within your browser. No webpage content is sent to external servers.

## Permissions

The extension uses browser permissions only to inspect the active webpage when you choose to use it and to store local extension settings.

## Third-Party Services

This extension does not use analytics, advertising, tracking services, or remote code.

## Contact

For questions about this privacy policy, please open an issue on the project's GitHub repository.
