# HTML Tree Generator Pro 🌳

**HTML Tree Generator Pro** is a powerful Chrome and Microsoft Edge browser extension that lets you visualize, inspect, search, filter, and export the complete HTML DOM structure of any webpage through an intuitive interactive tree view.

Designed for web developers, students, QA engineers, and UI/UX designers, the extension transforms complex webpage structures into an easy-to-navigate hierarchical tree, making debugging and learning HTML significantly faster and more efficient.

---

## ✨ Features

* 🌳 Interactive HTML DOM Tree Viewer
* 🔍 Real-time search by tag name, ID, class, text, and attributes
* 🎯 Smart filters for scripts, styles, comments, hidden elements, and empty nodes
* 📂 Expand/Collapse individual nodes or the entire tree
* 🧭 Keyboard navigation for faster browsing
* 📋 Detailed element information panel
* 📤 Export the DOM as **JSON**, **TXT**, or **HTML**
* 📄 Export the complete tree or only the selected node
* 📋 Copy exported content directly to the clipboard
* ⚡ Optimized rendering for large webpages
* 🎨 Clean, modern, and responsive user interface
* 🔒 100% local processing — no servers, tracking, or data collection

---

## 🚀 Why HTML Tree Generator Pro?

Modern websites contain deeply nested HTML structures that can be difficult to understand using traditional developer tools alone. HTML Tree Generator Pro provides a clear hierarchical representation of the DOM, making it easier to:

* Understand webpage structure
* Learn HTML and DOM relationships
* Debug complex layouts
* Inspect dynamically generated pages
* Analyze third-party websites
* Export DOM structures for documentation or research

---

## 📦 Export Options

The extension supports multiple export formats:

* JSON
* Plain Text (TXT)
* HTML

Exports can include either the entire document tree or only the currently selected node.

## 🛠️ Installation

### Developer Mode

1. Download or clone this repository.
2. Open your browser's extensions page:

   * Chrome: `chrome://extensions`
   * Edge: `edge://extensions`
3. Enable **Developer Mode**.
4. Click **Load unpacked**.
5. Select the extension folder.
6. Start exploring the HTML structure of any webpage.
