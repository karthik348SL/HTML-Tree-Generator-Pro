# Privacy Policy

Effective date: July 24, 2026

HTML Tree Generator Pro is designed to inspect webpage structure locally in your browser.

## Data Collection

The extension does not collect, sell, share, or transmit personal information.

## Page Content

When you click Generate Tree, the extension serializes the DOM structure of the active tab so it can display the tree in the viewer. This data remains local to your browser.

## Storage

The extension uses Chrome session storage to temporarily pass the serialized DOM snapshot from the capture workflow to the viewer tab. Session storage is local to your browser and is not sent to any external service.

## Clipboard

Clipboard access is used only when you explicitly click a copy action, such as copying a selector, XPath, HTML snippet, or export. Clipboard data is not transmitted.

## Network Requests

HTML Tree Generator Pro does not send DOM data, browsing history, page content, exports, or clipboard content to external servers.

## Permissions

The extension requests only the permissions needed for user-initiated DOM capture, viewer tab creation, and temporary local snapshot storage.

## Contact

For questions about this privacy policy, contact the extension publisher through the Chrome Web Store listing.
